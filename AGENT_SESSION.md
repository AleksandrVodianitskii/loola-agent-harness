# Журнал разработки с Codex

**25 ноября 2026**

Это сокращённый журнал рабочего сеанса. В нём зафиксированы запрос, принятые решения и результаты проверок.

| Этап | Действие и результат |
| --- | --- |
| Постановка | Пользователь предоставил исходный Python-цикл с одним инструментом Bash и попросил ленивую подгрузку скиллов, компактацию, замеры, ответы на два технических вопроса и публикацию. Рабочая папка была пустой. |
| Реализация | Разнесли работу по реестру скиллов, компактации и воспроизводимому бенчмарку. В основном цикле реализовали запросы Chat Completions, учёт usage, проверку пакетов вызовов и обработку отказов. |
| Интеграция | Проверили, что активация не меняет шлюзы и что повтор запроса к провайдеру не переисполняет завершённый ход. Валидацию Unicode добавили до записи контрольной точки, чтобы в сводку попадали значения, сериализуемые в UTF-8. |
| Тесты | `python3 -m unittest discover -v` прошёл 23 теста. Проверены целостность пакетов, контрольные точки, переполнение, ограничение вывода и разделение ожидаемых ошибок инструментов и ошибок хоста. |
| Замеры | `python3 -m benchmark --output benchmark/results.json` сравнил исходный цикл и новый харнесс. При окне 4 096 исходный цикл выполнил 3 из 32 пакетов, улучшенный выполнил 32 из 32 и прошёл проверки аудита. Широкое окно позволило завершить тот же объём исходным циклом. |
| Оговорка | В рабочей сессии не было настроенного Chat Completions-эндпоинта. Опубликованные замеры получены от детерминированной имитации. В бенчмарке есть режим для реального провайдера. |

**26 ноября 2026**

Пользователь попросил отдельно проверить механизм на реальной модели и сохранить сессию. Codex подготовил A/B-сценарий и запустил Qwen3‑8B через локальный Chat Completions-эндпоинт llama.cpp. Контрольный запуск получил HTTP 400 после восьмого лога. Харнесс с компактацией прочитал все 11 логов и создал верный отчёт. Проверка связала запись отчёта с запросом, в котором точный идентификатор профиля присутствовал в компактной сводке. Запись диалога и событий сохранена в [live-trace.jsonl](benchmark/live-trace.jsonl), счётчики провайдера и результаты проверки — в [live-results.json](benchmark/live-results.json).
